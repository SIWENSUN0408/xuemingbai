# 学明白

将任意学习材料转化为"测验 + 导图 + 音频"三位一体的个性化学习包。

## 工作流总览

```
输入解析 → 适配配置 → 三模态生成 → 打包交付
```

四阶段严格按顺序执行，每阶段完成后再进入下一阶段。

---

## 阶段一：输入解析与预处理

### 1.1 识别输入类型

| 输入类型 | 处理方式 |
|---------|---------|
| PDF 文件 | 运行 `scripts/pdf_ocr_extract.py` 提取文本；扫描件自动 OCR |
| 教材（整本/章节） | 用户指定章节则只处理该范围；整本则按目录分章，优先处理核心章节 |
| 话题关键词 | 基于关键词构建知识框架，必要时调用搜索补充权威内容 |

### 1.2 提取核心知识结构

从解析后的文本中识别：
- **核心概念**：定义、关键术语、理论框架
- **逻辑关系**：因果、递进、对比、并列
- **重点难点**：反复出现的概念、复杂推导、易混淆点
- **应用场景**：案例、实证、习题

输出一份内部知识大纲（不交付给用户），作为后续三模态生成的统一基础。

---

## 阶段二：年级与专业适配配置

### 2.1 确定年级水平

用户明确指定时直接使用；未指定时，根据材料难度和用户上下文推断。无法推断时默认本科。

### 2.2 加载适配规则

读取 `references/level-adaptation.md`，按年级确定：
- **内容深度**：本科重基础理解，硕士重批判分析，博士重前沿与方法论
- **语言风格**：参考对应学段学位论文的写作规范
- **题目类型**：本科参考期末测试，硕博参考专业课笔试

### 2.3 专业适配

全学科通用。根据输入材料所属学科，自动调整：
- 术语使用（保留学科专有名词，不做过度通俗化）
- 案例选择（优先使用该学科经典案例）
- 理论框架（遵循该学科主流范式）

---

## 阶段三：三模态内容生成

三种产物**并行生成**，均基于阶段一的知识大纲和阶段二的适配配置。

### 3.1 极简交互测验（HTML）

1. 读取 `assets/quiz-template.html` 作为模板
2. 读取 `references/quiz-patterns.md` 确定题型与数量
3. 基于知识大纲生成题目，填入模板
4. 题目要求：
   - 覆盖核心概念、逻辑关系、重点难点
   - 包含答案解析（点击后显示）
   - 本科：选择/判断/简答为主；硕博：论述/案例分析/文献批判为主
5. 输出独立 HTML 文件，可直接在浏览器打开

### 3.2 思维导图（Mermaid + 图像）

1. 基于知识大纲生成 Mermaid `mindmap` 语法
2. 结构要求：
   - 中心节点为主题
   - 一级分支为核心模块（3-5个）
   - 二级分支为关键概念
   - 三级及以下为细节/案例
   - 节点数量控制在 30-50 个，避免过度密集
3. 输出 `.mmd` 源码文件
4. 使用 Mermaid 渲染工具生成 PNG/SVG 图像（若环境支持 mermaid-cli，否则交付源码并说明渲染方式）

### 3.3 音频课程（mp3）

1. 读取 `assets/audio-script-template.md` 确定脚本结构
2. 撰写音频脚本，要求：
   - 时长 5-15 分钟（约 1000-3000 字）
   - 口语化表达，避免长难句和书面语
   - 结构：引入 → 核心概念讲解 → 逻辑梳理 → 重点总结 → 思考题
   - 年级适配：本科多用类比和例子，硕博多讲争议和方法论
3. 调用 `text_to_audio` 工具生成 mp3
   - prompt 中明确：专业讲解风格，语速适中，情绪平稳
   - 不指定 duration，由脚本长度自然决定

---

## 阶段四：打包交付

### 4.1 交付清单

| 产物 | 格式 | 说明 |
|------|------|------|
| 交互测验 | `.html` | 单文件，含样式和脚本 |
| 思维导图源码 | `.mmd` | Mermaid 源码 |
| 思维导图图像 | `.png` 或 `.svg` | 渲染后的图像（若可用） |
| 音频课程 | `.mp3` | 音频文件 |
| 学习指南 | 回复文本 | 简要说明如何使用三种产物 |

### 4.2 交付方式

- 所有文件通过 `present_files` 交付
- 在回复中给出使用建议：先听音频建立整体认知 → 看思维导图梳理结构 → 做测验检验掌握程度

## 资源索引

| 文件 | 用途 | 何时读取 |
|------|------|---------|
| `scripts/pdf_ocr_extract.py` | PDF 文本提取与 OCR | 输入为 PDF 时 |

## 质量自检

生成完成后，对照 `references/output-standards.md` 逐项检查：
- 测验：题目是否覆盖核心知识点？解析是否清晰？
- 导图：结构是否逻辑清晰？节点是否过多/过少？
- 音频：脚本是否口语化？时长是否合理？

不达标则修正后再交付。
