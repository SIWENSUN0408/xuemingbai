# 输出质量验收标准

生成完成后，按本文件逐项自检。不达标项必须修正后再交付。

## 一、交互测验（HTML）

### 内容质量
- [ ] 题目数量符合 `quiz-patterns.md` 中的学段配置
- [ ] 核心概念覆盖率 ≥ 80%
- [ ] 易:中:难比例约为 3:5:2
- [ ] 每道题均有答案解析
- [ ] 解析包含知识点定位和拓展思考
- [ ] 无错题、无歧义题、无答案提示关系

### 技术质量
- [ ] 单 HTML 文件，无外部依赖（CSS/JS 内联）
- [ ] 可直接在浏览器打开，无需服务器
- [ ] 选择题/判断题点击后即时反馈
- [ ] 主观题答案默认隐藏，点击展开
- [ ] 页面响应式，手机和电脑均可正常显示
- [ ] 无控制台报错

### 交互体验
- [ ] 页面顶部有标题和学段标识
- [ ] 有进度指示（当前第几题/共几题）
- [ ] 客观题有得分统计
- [ ] 底部有重新作答按钮
- [ ] 配色简洁，不使用花哨动画

## 二、思维导图（Mermaid + 图像）

### 结构质量
- [ ] 中心节点明确，为学习主题
- [ ] 一级分支 3-5 个，对应核心模块
- [ ] 节点总数 30-50 个
- [ ] 层级不超过 4 级
- [ ] 逻辑关系清晰：并列/递进/因果区分明确
- [ ] 无孤立节点，无重复节点

### 内容质量
- [ ] 节点表述简洁，每个节点 ≤ 15 字
- [ ] 核心概念全部纳入
- [ ] 重点概念有标识（可用 emoji 或特殊标记）
- [ ] 专业术语使用准确

### 技术质量
- [ ] Mermaid 语法正确，可正常渲染
- [ ] 使用 `mindmap` 图表类型
- [ ] 源码文件编码为 UTF-8
- [ ] 若生成图像，图像清晰可读，文字不模糊

## 三、音频课程（mp3）

### 脚本质量
- [ ] 时长 5-15 分钟（约 1000-3000 字）
- [ ] 结构完整：引入 → 核心讲解 → 逻辑梳理 → 总结 → 思考题
- [ ] 口语化表达，句子长度 ≤ 25 字
- [ ] 无书面语堆砌，无长难句
- [ ] 年级适配：本科多例子，硕博多争议和方法论
- [ ] 专业术语发音清晰，关键术语有重复强调

### 音频质量
- [ ] mp3 格式，可正常播放
- [ ] 语速适中（约 200-250 字/分钟）
- [ ] 发音清晰，无明显机械感
- [ ] 无背景噪音，无断句错误
- [ ] 情绪平稳，专业讲解风格

### 内容质量
- [ ] 覆盖知识大纲的核心模块
- [ ] 逻辑连贯，过渡自然
- [ ] 有 1-2 个思考题引导后续学习
- [ ] 结尾有简明总结

## 四、整体交付

- [ ] 三种产物全部生成，无遗漏
- [ ] 文件命名规范：`主题_测验.html`、`主题_导图.mmd`、`主题_音频.mp3`
- [ ] 回复中有使用建议（听音频 → 看导图 → 做测验）
- [ ] 所有文件通过 present_files 交付
